# Documentation rules

- [README.md](../../README.md) is for humans: purpose, status, what the skill does, output, requirements. Read it first; CLAUDE.md does not repeat it
- CLAUDE.md holds only what an agent needs on top: implementation details, conventions, internal paths
- Information relevant to humans goes into README.md and is referenced from CLAUDE.md, never duplicated
- Update both files with every commit as necessary
